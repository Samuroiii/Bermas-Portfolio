# Joseph Vince Roi H. Bermas — Personal Portfolio

A responsive, single-page portfolio built with HTML5, CSS3, and vanilla JavaScript.

## Files
- `index.html` — page content and semantic structure
- `style.css` — responsive layout, colors, and visual styling
- `script.js` — mobile menu, active navigation, and project notice interactions
- `assets/flins-inspired-hero.jpg` — original generated fantasy artwork used in the hero

## Run in VS Code
1. Extract the ZIP file.
2. Open the `flins_portfolio` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension and choose **Open with Live Server**.

No build tools or package installation are required. Google Fonts are loaded from the internet; system fallbacks are included.

## Customize
- Update your introduction and project descriptions in `index.html`.
- Add real certificate details in the Certificates section when available.
- Add your public email, GitHub, or LinkedIn links in the Contact section when ready.
- Replace `assets/flins-inspired-hero.jpg` with an image you have permission to use. Keep the same filename or update the CSS path in `style.css`.

## Publish
You can deploy this static site using GitHub Pages:
1. Create a GitHub repository and upload the contents of this folder.
2. Open the repository's **Settings → Pages**.
3. Choose deployment from the `main` branch and the root folder.
4. Save and wait for GitHub Pages to provide the public URL.
